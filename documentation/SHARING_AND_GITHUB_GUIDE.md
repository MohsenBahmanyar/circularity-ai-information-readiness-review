# Sharing and GitHub guide

## Recommended public link

Upload only the contents of `PUBLIC_GITHUB_PACKAGE` to a clean GitHub repository. Create a versioned release using the tag `v1.0-manuscript-submission`. Use the GitHub Release URL as the manuscript reproducibility link because it freezes the submitted package more clearly than the changing repository homepage. The repository root URL remains useful for browsing.

If a DOI-backed institutional or Zenodo release is created later, use that DOI as the preferred permanent citation. No DOI is claimed in this package.

## What to upload

Upload the contents of `PUBLIC_GITHUB_PACKAGE`, including the supplement, derived Excel and CSV data, figures, figure code, documentation, and checksums.

## What must remain private

Do not upload `PRIVATE_ARCHIVE_ONLY`. It contains raw Scopus, Web of Science, IEEE Xplore, and targeted Scopus exports plus internal provenance workbooks. Do not upload publisher PDFs, downloaded full texts, credentials, Office lock files, temporary files, or old drafts.

## Links to share

- Committee: share the GitHub Release URL and optionally the repository root for browsing.
- Manuscript Data Availability statement: use the frozen GitHub Release URL until a DOI-backed archive exists.
- Journal supplementary upload: use `Supplementary_Material_v01.pdf` and the frozen public-data ZIP created beside the package root. Include the DOCX or tables workbook only if requested by the journal.
